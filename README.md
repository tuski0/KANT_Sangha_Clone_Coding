# KANT 상하농원 클론 코딩

상하농원 웹사이트의 주요 화면을 HTML과 CSS로 재현한 KANT 클론 코딩 과제입니다.
여러 페이지의 레이아웃, 이미지 배치, 내비게이션을 구현하며 웹 페이지 구조와 스타일링을 학습했습니다.

## 1. 프로젝트 개요

| 항목        | 내용                                                                            |
| ----------- | ------------------------------------------------------------------------------- |
| 프로젝트명  | KANT 상하농원 클론 코딩                                                         |
| 개발 기간   | 26.9.14 ~ 26.9.18                                                               |
| 구현 범위   | 메인, 농원소개, 짓다, 놀다, 먹다, 농원이야기, 회원가입 안내, 객실예약 관련 화면 |
| 참고 사이트 | [작성 필요: 상하농원 원본 사이트 주소]                                          |
| 배포 주소   | [작성 필요: 배포한 경우 추가, 없으면 행 삭제]                                   |

## 2. 사용 기술

| 기술        | 사용 내용                                                |
| ----------- | -------------------------------------------------------- |
| HTML        | 페이지 구조, 메뉴, 콘텐츠, 이미지 및 영상 배치           |
| CSS         | 색상·글꼴·간격 설정, Flexbox와 Grid 레이아웃, hover 효과 |
| 미디어 쿼리 | 먹다 페이지의 일부 레이아웃에 적용                       |

현재 HTML 12개와 CSS 9개로 구성된 정적 웹 프로젝트입니다. 별도의 패키지 설치나 빌드 과정이 없으며, JavaScript와 백엔드 코드는 포함되어 있지 않습니다.

CSS와 이미지는 콘텐츠 영역별로 구분했습니다. `book.html`은 HTML 내부의 스타일도 사용합니다.

## 4. 페이지별 구현 내용

| 페이지             | 파일           | 주요 화면 구성                                           |
| ------------------ | -------------- | -------------------------------------------------------- |
| 메인               | `index.html`   | 상단 메뉴, 메인 배너, 운영시간, 소식 제목 영역, SNS 안내 |
| 농원소개           | `intro.html`   | 농원 소개 글, 이미지, 소개 메뉴                          |
| 짓다               | `build.html`   | 햄공방 소개, 생산일정 표, 주요 제품, YouTube 영상 임베드 |
| 놀다               | `play.html`    | 전시관 소개, 연도 표시, 전시 이미지와 설명               |
| 상하키친           | `store1.html`  | 매장 소개, 대표 이미지, 주요 메뉴                        |
| 농원식당           | `store2.html`  | 매장 소개, 대표 이미지, 주요 메뉴                        |
| 파머스카페 상하    | `store3.html`  | 매장 소개, 대표 이미지, 주요 메뉴                        |
| 파머스마켓         | `store5.html`  | 매장 소개, 대표 이미지, 주요 메뉴                        |
| 농원소식           | `news.html`    | 소식 카드 목록, 카테고리 메뉴, 페이지 번호 UI            |
| 농부의일기         | `diary.html`   | 일기 카드 목록, 카테고리 메뉴, 페이지 번호 UI            |
| 회원가입           | `sign_up.html` | 가입 버튼, SNS 가입 안내, 제휴 브랜드 안내               |
| 객실예약 관련 소개 | `book.html`    | 빌리지 배너, 예약 안내, 다이닝·라운지·웨딩 소개          |

### 구현 범위

- HTML 파일 간 이동과 CSS로 구성한 화면을 중심으로 구현했습니다.
- 회원가입·SNS 로그인·객실예약·구매의 실제 처리 기능은 구현되어 있지 않습니다.
- 게시글 상세 조회, 페이지 번호에 따른 목록 변경, 일부 서브 메뉴는 화면 UI만 구성되어 있습니다.
- 반응형 처리는 `css/eat_css/food.css`의 900px 이하 구간에 일부 적용되어 있습니다.

## 5. 실행 방법

1. 프로젝트 폴더를 내려받습니다.
2. 폴더 안의 `index.html`을 웹 브라우저로 엽니다.
3. 상단 메뉴를 통해 각 페이지를 확인합니다.

Google Fonts와 YouTube 영상은 외부 리소스를 사용하므로 인터넷 연결이 필요합니다.
